
# Sistema de Control de Rescate y Adopción Animal

## Descripción
Prototipo estructural de un sistema web para gestionar
el registro y seguimiento de animales rescatados.

## Tecnologías
- HTML5
- Etiquetas semánticas
- Formularios HTML
- Tablas HTML

## Estructura del proyecto
- index.html: página principal.
- reportar.html: formulario de registro.
- rescates.html: listado de casos.
- assets/img/: recursos gráficos.

## Navegación
Las tres páginas se encuentran interconectadas
mediante enlaces HTML.
