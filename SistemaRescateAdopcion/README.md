
# Sistema de Control de Rescate y Adopción Animal

## Descripción
Prototipo estructural de un sistema web para gestionar
el registro y seguimiento de animales rescatados.

## Tecnologías
- HTML5
- Etiquetas semánticas
- Formularios HTML
- Tablas HTML

## Estructura del proyecto
- index.html: página principal.
- reportar.html: formulario de registro.
- rescates.html: listado de casos.
- assets/img/: recursos gráficos.

## Navegación
Las tres páginas se encuentran interconectadas
mediante enlaces HTML.

## Estructura del proyecto

El proyecto está compuesto por tres páginas HTML5 interconectadas:

- **index.html:** página principal del sistema de rescate y adopción animal.
- **reportar.html:** formulario para registrar nuevos animales rescatados.
- **rescates.html:** tabla para consultar los casos registrados.

### Tecnologías utilizadas

- HTML5.
- Etiquetas semánticas.
- Formularios HTML con validación.
- Tablas para presentar información.

### Objetivo

Desarrollar un prototipo estructural web para organizar y consultar información de animales rescatados.
